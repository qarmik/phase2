| Field            | Type   | Purpose                              |

| ---------------- | ------ | ------------------------------------ |

| timestamp        | string | ISO 8601 UTC time of event           |

| artifact\_id      | string | which artifact triggered             |

| model\_version    | string | version or hash of model             |

| input\_hash       | string | SHA-256 hash of input payload        |

| decision\_summary | string | short text reason/decision           |

| human\_id         | string | ID of human intervener               |

| human\_reason     | string | why the override/intervention        |

| output\_hash      | string | SHA-256 hash of output               |

| signature\_hash   | string | hash of entire record (immutability) |
